1) RPC GAME (theo code hiện tại)
================================================================================

1.1 rpc_list_realm_channels
  Body:
    p_character_id: string (uuid character)
    p_base_code: string   // vd sect_10_tc, hoặc template có {channel}
  Mục đích: liệt kê channel của 1 vùng (base)
  Code parse: channel_no / channelNo / channel / no
              realm_code / realmCode / code

1.2 rpc_join_secret_realm
  Body:
    p_character_id
    p_realm_code: string  // vd sect_10_tc_c03 (base + _c{channel 2 số})
  Mục đích: vào map/kênh
  Lấy realm_id từ: realm_id | realmId | id

1.3 rpc_leave_secret_realm
  Body:
    p_character_id
    p_realm_id: string
  Mục đích: rời map trước khi đổi kênh / rejoin

1.4 rpc_get_secret_realm_snapshot
  Body:
    p_character_id
    p_realm_id
    p_limit_players: number  // default ~200 (settings.snapshot_limit_players)
  Mục đích: lấy mobs (+ players) trên map hiện tại
  Mob lấy từ: snapshot.mobs | realm.mobs | secret_realm.mobs | ...
  Mob id: id | mob_id | mobId | realm_mob_id | monster_id | target_id
  Mob sống: alive/is_alive, status dead/killed, hp > 0
  Loại mob (đoán từ name/type): boss | elite | normal
    - boss: chứa boss, thu_linh, thulinh
    - elite: elite, tinh_anh, tinhanh
    - normal: normal, quai_vat, thuong

1.5 rpc_attack_realm_mob_v3   *** đòn farm chính ***
  Body:
    p_character_id
    p_realm_id
    p_mob_id
    p_skill_slot: 0          // code CỐ ĐỊNH skill thường, không lấy UI
    p_apply_counter: false  // không phản đòn quái (đổi 2026-07 — one-shot farm)
  Thành công: code coi kill nếu hp_after = 0 / flags killed
  Lỗi hay gặp (theo nhận dạng string trong message/reason):
    - mob_dead / target_dead / already_dead / not_alive / killed / defeated
    - no_mana / no_mp / not_enough mana...
    - not_joined / not_join
    - wrong_channel / channel_mismatch / invalid_realm / not_in_realm /
      realm_mismatch / mob_not_found / invalid_mob  (nhánh "lệch kênh/realm")
    - cooldown / too_soon
    - daily_limit / online_limit / time_limit

1.6 rpc_use_item  (hết mana)
  Body ưu tiên: { p_character_id, p_item_code }  // vd pill_lk_mp
  Fallback: p_item_id / p_inventory_item_id / p_qty...

1.7 rpc_list_inventory
  Body: p_character_id, p_locale: "vi"
  Mục đích: tìm itemId bình MP nếu use theo code fail

1.8 rpc_nh_shop_buy  (mua bình MP)
  Body:
    p_character_id
    p_shop_code: "alchemy" (default)
    p_item_code: cùng mã bình (pill_lk_mp...)
    p_qty: 10 hoặc 1

1.9 rpc_get_rebirth_quest_progress  (smart farm theo nhiệm vụ trùng sinh)
  Body: p_character_id
  Mục đích: biết còn cần giết normal/elite/boss bao nhiêu

4) LUỒNG FARM (cách bot "hiểu" 1 vòng)
================================================================================

A. Orchestrator lite mỗi tick:
   1. ensureRuntime (login, characterId, token)
   2. buildFarmEngineSettings(UI)
   3. runFarmAuto(...)
   4. nextDelayMs:
      - softRescan=true  → 400–3000ms (mob_dead / lệch kênh)
      - attackCount>0    → max(minFarmDelay~5s, result.nextDelayMs)
      - empty            → empty_scan_delay
   5. Log summary 1 dòng (rate-limit)

B. Engine runFarmAuto (rút gọn):
   1. Xác định tier map (auto theo level/realm acc hoặc override)
   2. regionPlan: chọn base_code (sect_... theo tier), học available (max 2)
   3. channelRange: [channel] hoặc [from..to]
   4. Nếu chưa currentRealm → join 1 candidate (base×channel)
   5. Snapshot → extract mobs theo priority (boss/elite/normal)
   6. Pick target (currentMob hoặc shift queue; bỏ blacklist)
   7. Attack skill_slot=0
   8. Lỗi:
      - no_mana → use pill (+ buy) → attack lại trong cùng tick
      - mob_dead → blacklist ~12s, clear queue, softRescan; streak≥3 leave+xoay kênh
      - channel/realm → hardRejoin (leave+join); fail streak → xoay kênh
      - cooldown → chờ attack CD
   9. Thành công: đếm kill (response + optional snapshot delta)
  10. Hết mob noMobCount≥N → leave + currentRealm=null → vòng sau kênh khác

C. Giả định quan trọng (CÓ THỂ SAI — cần user xác nhận):

   [?] Attack chỉ hợp lệ khi đã join đúng realm_id của kênh đó
   [?] skill_slot=0 là đòn thường, CD server ~5 giây

   [?] Không có API "ai đang đánh mob này" → bot không né người (trừ blacklist sau dead)
